# BeatFlow

BeatFlow é um jogo de ritmo para Android e desktop, desenvolvido no Godot 4.7.2. A Demo usa uma faixa de 60 segundos com quatro dificuldades: Easy, Medium, Hard e Expert.

## Jogar

No Godot 4.7.2, importe `project.godot` e execute o projeto. Escolha **Play → BeatFlow Demo**, selecione a dificuldade e toque em **START**. Use as cinco pistas na tela ou as teclas **A**, **S**, **D**, **F** e **G**. **Retry** reinicia a mesma faixa.

## Exportar para Android

Abra **Project → Export** e selecione **Android Demo**. O preset inclui o áudio e os quatro charts da Demo. O [guia Android](ANDROID_DEMO.md) reúne os requisitos de exportação e as regras de julgamento.
